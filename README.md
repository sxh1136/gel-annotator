# Automated Gel Annotation Tool

A web-based tool to speed up gel annotation without manually moving text boxes around in powerpoint or photoshop.

🔗 https://sxh1136.github.io/gel-annotator/

Features:
- Automatic detection and annotation of ladder bands
- Loaded presets of commonly used ladders 
- Rapidly add lane labels to your image
- Manual correction through the interactive editor
